## 📋 07-TEMPLATES/ — Ready-to-Use Documents

### `Document-Library-Templates.md` (12 KB)

**Contains 11 production-ready templates:**

1. **SHADOW Charter** (5 pages)
   - Core founding document
   - Defines Commons authority, member rights, arbitration
   - All members sign before first project

2. **Membership Agreement** (2 pages)
   - Individual member signs when joining
   - Confirms pseudonym, privacy understanding, obligations
   - Legally binding

3. **Team Leader Charter** (3 pages)
   - Project-specific
   - Defines Team Leader authority, accountabilities, decision rights
   - Unique per project

4. **Code of Conduct** (3 pages)
   - Behavioral standards for all members
   - Addresses harassment, discrimination, confidentiality
   - Enforceable via arbitration

5. **Privacy Policy** (4 pages)
   - GDPR-compliant (if applicable)
   - Explains data handling, encryption, retention
   - Addresses subject access requests

6. **Project Charter** (4 pages)
   - Every project must have this
   - Defines scope, objectives, timeline, budget
   - Specifies roles, decision process, compensation
   - Unique per project

7. **Contributor Agreement** (3 pages)
   - Each team member signs
   - Confirms role, expectations, compensation
   - IP ownership and confidentiality terms
   - Dispute/arbitration procedure

8. **Decision Log Template** (1 page)
   - Used for every major decision
   - Fields: What, Who, When, Why, Status
   - Archived monthly

9. **Project Status Report** (2 pages)
   - Team Lead submits weekly/biweekly
   - Progress, risks, blockers, decisions
   - Circulated to team + Commons (if needed)

10. **Dispute/Complaint Form** (2 pages)
    - Used when conflict cannot be resolved directly
    - Triggers arbitration process
    - Required before escalation to Level 3

11. **Arbitration Record** (3 pages)
    - Completed after arbitration hearing
    - Documents findings, reasoning, decision
    - Filed for appeal/future reference

**Use:**
- Customize the template for your context
- Don't leave any section blank (mark N/A if not applicable)
- Have relevant parties sign/accept
- Archive for later reference
